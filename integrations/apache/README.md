# Αφαίρεση της παραγράφου από την κύρια ιστοσελίδα

Η παράγραφος με την κλάση `mennoo-privacy-note` βρίσκεται στο `stands.php` της κύριας PHP ιστοσελίδας. Δεν περιλαμβάνεται στα αρχεία που δημοσιεύει το Cloudflare Pages από το `public/` αυτού του repository.

Στο τρέχον `stands.php` του MENNOO, αφαιρέστε μόνο το πλήρες στοιχείο:

```html
<p class="mennoo-privacy-note">Τα πρωτότυπα αρχεία 3MF δεν μεταφέρονται στον επισκέπτη. Τα δημόσια 3D μοντέλα GLB είναι απλοποιημένες εκδόσεις παρουσίασης και μπορούν να εξαχθούν από τον browser. Η μορφή του QR και οι διαστάσεις στην προεπισκόπηση είναι ενδεικτικές.</p>
```

Το `remove-3mf-note.patch` περιγράφει αυτή τη μοναδική αλλαγή. Δεν αντικαθιστά την υπόλοιπη σελίδα με παλιότερο αντίγραφο. Δεν προσθέτει άλλη παράγραφο στη θέση της.

Η αλλαγή χρειάζεται ξεχωριστή μεταφόρτωση στο PHP hosting. Το push στο repository του 3D viewer ενημερώνει μόνο το Cloudflare Studio.

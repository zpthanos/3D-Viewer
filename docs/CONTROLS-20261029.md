# Stand controls — 29 October 2026

The viewer now offers left/right rotation in 30° steps, a noninteractive centre
crosshair, fullscreen and larger design cards. Rotation buttons continue from
the current dragged camera angle. Activating 3D captures touch gestures; the
“Κύλιση σελίδας” button restores scrolling and stops rotation.

Fullscreen first uses the browser API. When unavailable or rejected, the scene
expands to the viewport with Escape/close support and focus isolation. Embedded
fallback fullscreen needs the updated main-site embed script and CSS delivered
with the MENNOO website ZIP. Native iframe fullscreen remains supported through
the existing `allow="fullscreen"` attribute.

The parent can select a model with `mennoo-stand-studio:select`, `version: 1`
and a known `design`. Only the existing approved parent origins and parent
window are accepted. Selection is acknowledged even when unchanged. The viewer
sends `mennoo-stand-studio:fullscreen` with a boolean `expanded` for the fallback.

Validation: dependency-free build and 49 Node tests passed, including touch
state, manual rotation, native/rejected fullscreen, Escape/focus restoration
and authenticated parent selection. Existing models are unchanged.
Browser visual QA and physical iOS/Android gestures remain unverified because
the managed preview daemon was unavailable in this execution environment.
